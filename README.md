# Octo intro motion — prototype

نمونه موشن شخصیت اکتو برای سایت Octoopus؛ شامل ورود نرم، حرکت شناور بدن و بازوها، تغییر جهت نگاه، پلک‌زدن و حرکت دهان هنگام تایپ.

## فایل‌های مخزن
- `index.html`: پیش‌نمایش تعاملی در مرورگر.
- `octoopus-character.svg`: فایل SVG شخصیت اصلی.
- `render.py`: اسکریپت تولید فریم‌ها، افکت‌های صوتی و ویدئوی MP4.
- `requirements.txt`: وابستگی‌های پایتون.

## پیش‌نمایش در مرورگر
چون پیش‌نمایش SVG را به‌صورت inline بارگذاری می‌کند، بهتر است آن را از طریق وب‌سرور محلی اجرا کنید، نه با بازکردن مستقیم فایل:

```bash
python -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کنید.

## ساخت ویدئو
نیاز دارید به Python 3، FFmpeg و فونت‌های Noto Arabic/DejaVu در مسیرهای تعریف‌شده در اسکریپت.

```bash
pip install -r requirements.txt
python render.py
```

اسکریپت پوشه `frames/`، تصاویر sprite، فایل `sfx_mix.wav` و خروجی `octo_intro.mp4` را می‌سازد. خروجی ویدئو 720×1280 است؛ فریم‌های پایه با 15fps رندر و در خروجی به 30fps تبدیل می‌شوند.

## صدا
افکت whoosh برای ورود و تیک‌های تایپ به‌صورت مصنوعی تولید می‌شوند. نریشن واقعی عمداً اضافه نشده تا بعداً صدای ضبط‌شده جداگانه سینک شود.

## فونت
هنوز فایل دقیق فونت سایت داخل مخزن قرار نگرفته است؛ تا وقتی منبع واقعی فونت از CSS سایت یا فایل فونت تأیید نشود، از جایگزین موجود در اسکریپت استفاده می‌شود.
