# Octo intro motion — prototype

نمونه اولیه موشن شخصیت اکتو برای سایت Octoopus؛ شامل ورود نرم از پایین، تایپ متن فارسی و افکت‌های صوتی تولیدشونده با اسکریپت.

## فایل‌های مخزن
- `index.html`: پیش‌نمایش انیمیشن در مرورگر؛ برای دیدن آن فایل را باز کنید.
- `octoopus-character.svg`: فایل SVG شخصیت.
- `render.py`: اسکریپت تولید فریم‌ها، افکت‌های صوتی و ویدئوی MP4.
- `requirements.txt`: وابستگی‌های پایتون.

## ساخت ویدئو
نیاز دارید به Python 3، FFmpeg و فونت‌های Noto Arabic در مسیرهای لینوکسی تعریف‌شده در اسکریپت. نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

سپس:

```bash
python render.py
```

اسکریپت پوشه `frames/`، دو تصویر دهان، فایل `sfx_mix.wav` و خروجی `octo_intro.mp4` را در کنار خودش می‌سازد. خروجی ویدئو 720×1280 با 30fps است؛ فریم‌های پایه با 15fps رندر می‌شوند.

## صدا
افکت whoosh برای ورود و تیک‌های تایپ به‌صورت مصنوعی تولید می‌شوند. صدای نریشن عمداً اضافه نشده تا بعداً صدای ضبط‌شده شما جداگانه روی تایم‌لاین سینک شود.

## نکته
فونت فعلی در اسکریپت از Noto Sans Arabic استفاده می‌کند. برای نزدیک‌شدن به تایپوگرافی سایت، می‌توان فایل فونت Vazirmatn را اضافه کرد و مسیر آن را در `render.py` تنظیم کرد.
