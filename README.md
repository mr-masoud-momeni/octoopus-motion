# Octo intro motion — prototype

این پروژه یک نمونه اولیه ۱۰ ثانیه‌ای از ورود اکتو، نمایش تایپ‌شونده متن فارسی و افکت‌های صوتی است.

## فایل‌ها
- `index.html`: پیش‌نمایش وب و انیمیشن.
- `octoopus-character-original.svg`: فایل اصلی SVG آپلودشده، بدون تغییر.
- `octoopus-character.svg`: نسخه آماده‌شده برای نمونه موشن.
- `render.py`: اسکریپت تولید فریم‌ها و خروجی MP4.
- `sfx_mix.wav`: افکت‌های صوتی؛ نریشن هنوز اضافه نشده.
- `octo_intro.mp4`: خروجی ویدئویی 720×1280، 30fps.

## رندر مجدد
نیازمندی‌ها: Python 3، Pillow، NumPy، CairoSVG و FFmpeg. اسکریپت از فونت Noto Sans Arabic موجود در لینوکس به‌عنوان فونت جایگزین استفاده می‌کند. برای تطابق دقیق با سایت، فایل Vazirmatn را می‌توان اضافه و مسیر فونت را در `render.py` تغییر داد.

در پوشه پروژه اجرا کنید:

```bash
python render.py
```

فریم‌ها داخل `frames/` و خروجی نهایی در `octo_intro.mp4` ساخته می‌شوند. اسکریپت برای سبک‌تر شدن رندر، فریم‌های اصلی را با 15fps تولید و در خروجی به 30fps تبدیل می‌کند.

## صدا و سینک
- افکت whoosh با بالا آمدن اکتو هماهنگ شده است.
- صدای تایپ به‌صورت تیک‌های کوتاه در زمان نمایش حروف قرار دارد.
- نریشن در خروجی نیست تا بعداً صدای ضبط‌شده شما روی تایم‌لاین اضافه شود.
