# اکـتوپوس — تمپلیت ریلز ۹:۱۶

یک صحنه‌ی ۱۰۸۰×۱۹۲۰ که کاراکتر «اکتو» را با همان SVG سایت متحرک می‌کند و متن‌ها را واژه‌به‌واژه وارد می‌کند. خروجی هم MP4 است، هم قابل ویرایش در مرورگر.

```
template/
├─ index.html          ← ادیتور زنده (باز کن، پلی، هر زمان را ببین)
├─ preview.html        ← پیش‌نمایش ویدیوی نهایی
├─ fonts.css + fonts/  ← وزیرمتن (آفلاین، بدون نیاز به گوگل فونت)
├─ out/
│  ├─ octo-template.mp4   ← خروجی رندر‌شده
│  ├─ frames/             ← فریم‌های PNG (برای رندر مجدد)
│  └─ stills/             ← عکس‌های تک‌فریم
└─ scripts/
   ├─ render.mjs        ← رندر با Chrome + FFmpeg
   └─ get-fonts.mjs     ← دانلود فونت
```

## ۱) دیدن و ویرایش

`index.html` را در مرورگر باز کن. تمام.

- با اسلایدر می‌توانی هر لحظه را ببینی (برای تنظیم دقیق تایمینگ).
- `safe-zones` محدوده‌ای را نشان می‌دهد که رابط اینستاگرام روی ویدیو می‌افتد.

## ۲) عوض کردن متن ریلز

بالای `index.html`، آبجکت `CFG` را تغییر بده. هر صحنه یک `beat` است:

```js
{
  t0: 0.00, t1: 2.00,              // شروع و پایان (ثانیه)
  title: "سایتت [[سفید]] شده؟",   // [[...]] = کلمه‌ی فیروزه‌ای با خط
  sub: "قبل از هر کاری، اینو ببین",
  mouth: "surprise",               // happy | sad | surprise
  gaze: [0.0, -0.15],              // نگاه: -1 تا 1 افقی / عمودی
  sweep: false                     // خط اسکن در شروع صحنه
}
```

- `duration` طول کل ریلز است؛ اگر صحنه اضافه کردی، `t0`/`t1` را هم به‌روز کن.
- `blinks` فهرست لحظه‌های پلک زدن است (ثانیه مطلق).
- `replace` چیپ CTA: فیلد `chip` در هر beat.

## ۳) رندر گرفتن

```bash
node scripts/render.mjs --video --html reel-01.html    # → out/octo-template.mp4
node scripts/render.mjs --video --fps 60   # نرم‌تر
node scripts/render.mjs --stills 1,3,5 --html reel-01.html  # چند عکس برای بررسی
```

نیاز: Node 18+، Google Chrome، FFmpeg در PATH. مسیر کروم اگر جای دیگری است:
`set CHROME_PATH=C:\path\to\chrome.exe`

## ۴) صدا

خروجی بدون صوت است؛ در کپ‌کات/پریمیر صدای خودت را روی آن بگذار. نکته‌ها:

- ویدیو در ۳۰fps است، پروژه را ۳۰fps بساز.
- صدای اکتو نازک/کمی بالاتر از صدای خودت، ولی با همان لحن خودت.
- برای زیرنویس، فونت **وزیرمتن Black (900)** و رنگ سفید با کلمه‌ی کلیدی فیروزه‌ای `#41FAF1`.

### ۴-۱) ضبط، سینک خودکار، رندر (روش پیشنهادی)

صدای خودت را **یک‌جا** و با مکث (حداقل ۰.۳۵ ثانیه، بهتر ۰.۴ تا ۰.۵) بین جمله‌ها ضبط کن.
متن جمله‌ها در `audio/script.txt` است و **برچسب‌دار** — یعنی هر خط می‌گوید کدام
چیز روی صفحه باید ظاهر شود:

```
b0 | سایتت سفید شده؟ قبل هر کاری این مسیر رو برو.   ← تیتر صحنهٔ ۱
b2 | سه علت داره. هر کدوم اثر انگشت خودش رو داره.
c0 | افزونهٔ ناسازگار. پنل باز می‌شه، ولی سایت سفیده.  ← کارت علت ۱
q0 | پنل باز می‌شه؟ آره، سمت فرانت خراب شده.          ← سوال ۱
```

| برچسب | معنی |
|---|---|
| `b0`…`b5` | تیتر و زیرنویس هر صحنه (۶ بیت) |
| `c0`…`c2` | کارت‌های سه علت |
| `q0`…`q1` | دو سوال تشخیصی |

بعد:

```bash
node scripts/timing.mjs --audio audio/voice.wav --lines audio/script.txt --out timing.json

node scripts/render.mjs --html reel-01.html --video --timing timing.json --audio audio/voice.wav --out reel-01.mp4
```

**چی از روی صدا تنظیم می‌شود:** زمان هر بیت، لحظهٔ ظاهر شدن هر کارت و سوال،
زوم دوربین، لحظهٔ کلیک کرسر روی لاگ، و حتی پلک زدن اکتو. یعنی **سرعت خواندن
تو ریتم ویدیو را می‌سازد**.

اگر تعداد بخش‌های صوتی با تعداد خط‌های اسکریپت فرق کند، سیستم خودش تطبیق می‌دهد
(بخش‌های اضافه به هم می‌چسبند یا بلندترین بخش نصف می‌شود) — ولی **ترتیب** خواندن
باید با ترتیب فایل اسکریپت یکی باشد.

اگر تایمینگ پس از شنیدن صدا کمی لنگ بود، فقط `timing.json` را دستی ویرایش کن و دوباره رندر بگیر.

## ۵) موتور نسخهٔ ۲ (فقط در `reel-01.html`)
- **ریگ دوربین:** پوش‌این، وایپ، اسنپ‌زوم
- **مانیتور سه‌بعدی** با پرسپکتیو و چند حالت صفحه (سفید / لاگ / سایت)
- **کرسر** با حرکت و ریپل کلیک
- **کارت‌های علت** و **سوال‌ها** با ورود ضربه‌ای و محو شدن
- **نوار مسیر** بالای صفحه (مشکل ← علت ← تشخیص)
- **تایم‌لاین نسبی:** هر کی‌فریم با `b` (شمارهٔ صحنه) و `o` (آفست) نوشته می‌شود، پس با تغییر تایمینگ صدا کل صحنه خودکار جابه‌جا می‌شود.

```js
camera: [ { b: 0, o: 0.0, s: 1.00, x: 0, y: 0 },
           { b: 4, o: 1.0, s: 1.15, x: 0, y: 70 } ],
char:   [ { b: 1, o: 0.4, scale: 0.52, x: -300, y: 40 } ],
```

### هایلایت کلمه‌ها

| نشانه | نتیجه |
|---|---|
| `[[کلمه]]` | فیروزه‌ای + خط زیر کلمه (هایلایت معمول برند) |
| `{{کلمه}}` | بلوک سفید با متن سرمه‌ای — یعنی خودِ صفحهٔ سفید داخل جمله (با فلیکر CRT) |

مثال: `"سایتت {{سفید}} شده؟"` — کلمهٔ «سفید» به‌جای فیروزه‌ای، یک تکه صفحهٔ سفید می‌شود.

## ۶) افکت‌های صوتی (خودکار)

موتور هر لحظهٔ مهم را اعلام می‌کند (`window.OCTO_EVENTS`) و رندرر برای هر کدام
افکت می‌سازد و دقیقاً سر جایش می‌چسباند. همهٔ افکت‌ها با ffmpeg ساخته می‌شوند
(هیچ فایل صوتی لازم نیست) — `scripts/sfx.mjs`:

| افکت | کِی |
|---|---|
| `rise` | اکتو از اعماق بالا میاد |
| `pop` | بلوک «سفید» و کارت‌های علت ظاهر می‌شن |
| `sweep` | خط اسکن بین صحنه‌ها |
| `whoosh` | ورود مانیتور |
| `zap` | روشن شدن صفحهٔ سفید / باز شدن لاگ |
| `tick` | تیک خوردن سوال‌ها |
| `click` | کلیک کرسر روی خط لاگ |
| `ding` | چیپ CTA |

## ۷) یک‌دستوری: از صدا تا ویدیو

### الف) خواندن روی ویدیو (پیشنهادی — همگام‌سازی دقیق)

```bash
node scripts\build.mjs --readalong
```

ویدیو **ریتم ثابت** دارد (۴۰.۶ ثانیه) و صدای تو دقیقاً روی همان تایم‌لاین
نشانده می‌شود — یعنی صدا هیچ‌وقت از تصویر عقب نمی‌افتد.

روش کار:
1. `out/reel-01-guide.mp4` را ببین (ویدیوی راهنما با افکت‌ها، بدون صدا)
2. روی همین ویدیو ضبط کن: هر جا متن روی صفحه اومد، بخون
3. فایل ضبطت را بذار تو `audio/`
4. `node scripts\build.mjs --readalong` را بزن

`out/pace-guide.txt` هم ساخته می‌شود: دقیقاً می‌گوید هر جمله بین چه ثانیه‌ای
باید خوانده شود.

### ب) صدا ریتم ویدیو را بسازد

```bash
node scripts/build.mjs        # یا: دابل‌کلیک روی build.bat
```

این دستور خودش:
1. فایل صوتی پوشهٔ `audio/` را پیدا می‌کند
2. **مکث‌های بلند را می‌بُرد** (نویز اتاق و مکث‌های اضافه حذف می‌شوند، با محافظ که کلماتت را نبرد)
3. تایم‌لاین را از روی صدای فشرده می‌سازد
4. ویدیو را با صدا و افکت رندر می‌کند → `out/reel-01.mp4`

تنظیمات حالت «ب»:

```bash
node scripts/build.mjs --speed 1.08   # کمی تندتر کردن صدا
node scripts/build.mjs --cut 1.0      # مکث‌های بیشتر از این (ثانیه) بریده شوند
node scripts/build.mjs --keep 0.4     # این مقدار سکوت بین جمله‌ها بماند
node scripts/build.mjs --raw          # بدون فشرده‌سازی، صدای خام
```

اگر فقط عوض کردن صدا/افکت‌ها لازمه (بدون رندر دوبارهٔ تصویر):

```bash
node scripts/render.mjs --html reel-01.html --video --mux-only \
  --timing timing.json --audio out/voice-clean.wav --sfx --out reel-01.mp4
```
