# اسکریپت خواندن ریلز ۱ — «صفحهٔ سفید»
#
# هر خط = یک چیزی که روی صفحه ظاهر می‌شه. برچسب سمت چپ خط را ننویس.
#
# چطور ضبط کن (مهم!):
#   • همه را در یک‌جا و پشت‌سرهم بخوان، بدون قطع کردن ضبط
#   • بین هر خط فقط ~۰.۳ تا ۰.۴ ثانیه مکث کن (نه بیشتر)
#   • داخل یک جمله مکث نکن — مخصوصاً بعد از «؟»ها
#   • اتاق ساکت باشد یا گوشی را نزدیک‌تر بگیر (نویز اتاق سینک را خراب می‌کند)
#   • مکث‌های بلند خودکار بریده می‌شوند، ولی کوتاه‌تر بهتر است
#
# برچسب‌ها:
#   b0..b5  = تیتر و زیرنویس هر صحنه
#   c0..c2  = کارت‌های سه علت
#   q0..q1  = دو سوال تشخیصی

b0 | سایتت سفید شده؟ قبل هر کاری این مسیر رو برو.
b1 | خطاش رو نمی‌بینی. صفحهٔ سفید یعنی خطا هست، ولی پنهانه.
b2 | سه علت داره. هر کدوم اثر انگشت خودش رو داره.
c0 | افزونهٔ ناسازگار. پنل باز می‌شه، ولی سایت سفیده.
c1 | خطای PHP. یه خطای PHP در قالب یا کد.
c2 | کمبود حافظه. حافظهٔ PHP تموم شده.
b3 | از کجا شروع کنم؟ دو تا سوال.
q0 | پنل باز می‌شه؟ آره، سمت فرانت خراب شده.
q1 | آخرین چیزی که عوض کردی چی بود؟ آپدیت؟ پلاگین؟ محتوا؟
b4 | جوابش توی لاگه. فقط یه خط.
b5 | بذار ببینم. تحلیل رایگان، همین امروز.
