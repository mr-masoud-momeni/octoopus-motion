چطور اصولی رنگ‌بندی کنی؟

هر رنگ باید جای خودش رو داشته باشه؛ این ۵ نقش رو بشناس.
01

رنگ اصلی

در هدر، لوگو و بخش‌های شاخص سایت استفاده می‌شه. رنگی انتخاب کن که با شخصیت برندت هماهنگ باشه و کنار رنگ‌های دیگه خوب دیده بشه.

02

رنگ تأکیدی

برای دکمه خرید، ثبت سفارش و پیشنهادهای مهمه. رنگی متمایز از رنگ‌های غالب انتخاب کن تا اقدام اصلی سریع به چشم بیاد.

03

رنگ پس‌زمینه

برای بدنه صفحه، بخش‌ها و کارت محصولات استفاده می‌شه. رنگی خنثی و آرام انتخاب کن تا تمرکز روی خود محصول باقی بمونه.

04

رنگ متن

برای عنوان‌ها، توضیحات و قیمت‌هاست. رنگ متن باید با پس‌زمینه کنتراست کافی داشته باشه تا خواندنش راحت باشه.

05

رنگ وضعیت

برای پیام موفقیت، خطا، هشدار و موجودی استفاده می‌شه. از رنگ‌های آشنا و ثابت استفاده کن و پیام رو فقط با رنگ منتقل نکن.

این ۵ نقش لزوماً به معنی ۵ رنگ متفاوت نیست.
ذخیره کن تا موقع طراحی فروشگاهت به کارت بیاد.
