# اینفوگرافی ثابت — راهنمای رنگ‌بندی فروشگاه

این پروژه یک پوستر ثابت ۱۰۸۰×۱۹۲۰ (نسبت ۹:۱۶) برای انتشار به‌صورت Reel است؛ انیمیشن یا کاراکتر متحرک ندارد.

## اجرا و پیش‌نمایش
فایل `index.html` را در مرورگر باز کن. فونت وزیرمتن از مسیر `../../template/fonts/vazirmatn.woff2` بارگذاری می‌شود.

## خروجی PNG
از رندرر فعلی پروژه استفاده کن:

```bash
cd octo-reels/template
node scripts/render.mjs --html ../projects/color-guide/index.html --stills 0
```

فریم خروجی در `octo-reels/template/out/stills/t-0.00.png` ساخته می‌شود.

## هویت بصری
- سرمه‌ای: #0A192F
- سرمه‌ای دوم: #142B4D
- فیروزه‌ای: #41FAF1
- متن فرعی: #B4BCD0
- فونت: Vazirmatn
- پس‌زمینه گرادیانی، کارت‌های شیشه‌ای مات، بدون تصویرسازی داخل کارت‌ها

متن هر کارت عمداً به‌صورت یک پاراگراف نوشته شده تا محل استفاده و راهنمای انتخاب را یک‌جا توضیح دهد.
