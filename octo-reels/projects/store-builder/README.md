# ریلز فروشگاه‌ساز — نسخهٔ اولیه

این پروژه یک نسخهٔ اولیه برای معرفی فروشگاه‌ساز Laravel است؛ مستقل از پروژه‌های دیگر و بدون تغییر در تمپلیت اصلی.

## ایدهٔ سناریو
1. هوک: «برای فروش آنلاین، همه‌چی باید پیچیده باشه؟»
2. فروشگاه با دامنهٔ اختصاصی
3. ثبت سفارش بدون عضویت مشتری
4. پرداخت کارت‌به‌کارت
5. اعلان سفارش در بات بله و تأیید فروشنده
6. جمع‌بندی و پرسش برای تعامل: «تو چی می‌فروشی؟»

## پیش‌نمایش
فایل `v1.html` را در Chrome باز کن. کنترل پایین صفحه برای پخش، توقف، شروع مجدد و جابه‌جایی در تایم‌لاین است.

## رندر آزمایشی
از ریشهٔ مخزن اجرا کن:

```bash
node octo-reels/template/scripts/render.mjs --stills 1,3,5,9,13,17,20,24,26 --html ../projects/store-builder/v1.html
```

## خروجی MP4 با افکت صوتی
```bash
node octo-reels/template/scripts/render.mjs --video --sfx --html ../projects/store-builder/v1.html --out store-builder-v1.mp4
```

خروجی در `octo-reels/template/out/store-builder-v1.mp4` ذخیره می‌شود.

## نکته
- مدت ویدئو ۲۸ ثانیه است.
- هنوز گویندگی اضافه نشده؛ متن‌ها و زمان‌بندی برای بازبینی اولیه‌اند.
- اعلان بات بله به شکل نمایشی بازسازی شده است، نه اسکرین‌شات واقعی.
- فایل‌های تمپلیت و پروژه‌های قبلی دست‌نخورده باقی می‌مانند.
