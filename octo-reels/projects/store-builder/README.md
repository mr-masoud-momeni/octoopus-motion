# ریلز اُکتوشاپ — نسخهٔ بازطراحی‌شده

این نسخه ابتدا شلوغی راه‌اندازی فروشگاه را با پاپ‌آپ‌های پشت‌سرهم نشان می‌دهد، سپس با دو راه‌حل ساده به معرفی اُکتوشاپ می‌رسد. فایل‌ها در همان شاخهٔ `main` و در پوشه‌ای مستقل قرار دارند.

## ترتیب روایت
1. هوک: «برای فروش آنلاین، باید این‌همه دردسر بکشی؟»
2. پاپ‌آپ‌های نامنظم: طراح، هاست، انتخاب طرح، مجوز، درگاه و هزینه‌ها.
3. مکث و تغییر ریتم: «حالا فکر کن همهٔ این‌ها رو بشه با فقط دو چیز جایگزین کرد…»
4. دو کارت با تیک سبز: «دامنهٔ خودت» و «یک شماره کارت».
5. معرفی اُکتوشاپ با شعار: «فروشگاهت رو ساده شروع کن.»
6. پایان: «تو چی می‌فروشی؟»

## پیش‌نمایش
فایل `v1.html` را در Chrome باز کن. کنترل پایین صفحه برای پخش، توقف، شروع مجدد و جابه‌جایی در تایم‌لاین است.

## رندر آزمایشی
از ریشهٔ مخزن اجرا کن:

```bash
node octo-reels/template/scripts/render.mjs --stills 1,3,5,7,9,11,14,16,19,21 --html ../projects/store-builder/v1.html
```

## خروجی MP4 با افکت صوتی
```bash
node octo-reels/template/scripts/render.mjs --video --sfx --html ../projects/store-builder/v1.html --out octoshop-v1.mp4
```

خروجی در `octo-reels/template/out/octoshop-v1.mp4` ذخیره می‌شود.

## نکته‌ها
- مدت ویدئو ۲۳ ثانیه است.
- هنوز گویندگی اضافه نشده؛ زمان‌بندی و متن‌ها برای بازبینی‌اند.
- اشاره به مجوز و درگاه، نمایش دردسرهای رایج است؛ منظور حذف الزام‌های قانونی کسب‌وکار نیست.
- فایل‌های تمپلیت و پروژه‌های قبلی دست‌نخورده باقی می‌مانند.
