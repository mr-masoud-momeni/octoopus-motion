# پروژهٔ مستقل معرفی اکتو

سناریوی آغازین: «سلام، من اکتو هستم؛ یک توسعه‌دهنده در اعماق!»

## پیش‌نمایش
فایل `index.html` را در Chrome باز کنید. کنترل پایین صفحه برای پخش، توقف، شروع مجدد و جابه‌جایی روی تایم‌لاین است.

## گرفتن فریم‌های آزمایشی
اسکریپت رندر فعلی در تمپلیت حفظ شده است. از ریشهٔ مخزن اجرا کنید:

```bash
node octo-reels/template/scripts/render.mjs --stills 0.5,2.8,5.4,6.8 --html ../projects/intro/index.html
```

مسیر `--html` نسبت به `octo-reels/template` محاسبه می‌شود. فریم‌ها در `octo-reels/template/out/stills` قرار می‌گیرند.

## خروجی ویدئو
```bash
node octo-reels/template/scripts/render.mjs --video --html ../projects/intro/index.html --out octo-intro.mp4
```

ویدئو در `octo-reels/template/out/octo-intro.mp4` ذخیره می‌شود. نیازمندی‌ها: Node.js، Chrome و FFmpeg.

## نکات اجرایی
- صحنه و انیمیشن در همین فایل مستقل قرار دارند؛ تمپلیت اصلی و فایل‌هایش تغییر نکرده‌اند.
- `window.renderAt(t)` انیمیشن را برای زمان مشخص تنظیم می‌کند تا رندر فریم‌به‌فریم تکرارپذیر باشد.
- حرکت پاها عمداً محدود است و پلک و نگاه با تغییرات کوچک کنترل می‌شوند.
- ابتدا فریم‌های آزمایشی را بررسی کنید؛ بعد رندر کامل بگیرید.
