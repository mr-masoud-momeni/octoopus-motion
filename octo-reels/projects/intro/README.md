# معرفی اکتو — پروژهٔ مستقل

این پوشه برای ساخت ریلز معرفی اکتو است و عمداً از پوشهٔ `template/` جدا نگه داشته می‌شود.

## سناریوی پایه
«سلام، من اکتو هستم؛ یک توسعه‌دهنده در اعماق!»

## اصول اجرا
- تمپلیت اصلی و فایل‌های آن دست‌نخورده می‌مانند.
- از همان روش رندر مرورگری استفاده می‌کنیم: HTML/CSS + JavaScript + SVG، سپس Chrome و FFmpeg.
- فونت‌ها و دارایی‌ها از فایل‌های محلی پروژه استفاده می‌شوند؛ مسیرها باید از همین پوشه درست resolve شوند.
- انیمیشن باید تابع زمان باشد تا بتوان هر فریم را دقیق و تکرارپذیر رندر کرد.
- حرکت اندام‌ها باید حول محل اتصال واقعی انجام شود؛ چشم‌ها و دهان نرم و کنترل‌شده حرکت کنند.
- قبل از رندر کامل، چند فریم کلیدی خروجی می‌گیریم و از نظر چیدمان فارسی، حرکت شخصیت و ترکیب‌بندی بررسی می‌کنیم.

## مراحل
1. ساخت صحنهٔ مستقل و انتقال/استفادهٔ مجدد از ریگ SVG اکتو.
2. طراحی زمان‌بندی جمله و حرکت‌های متناسب با آن.
3. گرفتن stills برای بررسی بصری.
4. اصلاح ایرادها و سپس رندر MP4.

این README فقط مشخصات شروع پروژه است؛ تمپلیت اصلی در `octo-reels/template/` تغییر نمی‌کند.
