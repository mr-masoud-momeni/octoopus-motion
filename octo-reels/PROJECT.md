## ۴) آنچه ساخته شد

مسیر: `octo-reels/template/`

```
index.html        ادیتور زندهٔ ۱۰۸۰×۱۹۲۰ (اسلایدر زمان + safe-zone) — دموی ۶ ثانیه‌ای
reel-01.html      ریلز ۱ «صفحهٔ سفید» ۴۰ ثانیه‌ای + موتور نسخهٔ ۲
preview.html      پیش‌نمایش ویدیو
README.md         راهنمای ویرایش و رندر
fonts/            وزیرمتن آفلاین
audio/script.txt  متن جمله‌های دیالوگ ریلز ۱ (برای ضبط و سینک)
out/
  octo-template.mp4   دموی ۶ ثانیه‌ای، ۳۰fps، بدون صدا
  reel-01.mp4         ریلز ۱ (بی‌صدا)
  poster.png
scripts/
  render.mjs      رندر با Chrome (CDP) + FFmpeg  (--html --audio --music --timing)
  timing.mjs      ساخت تایم‌لاین از روی صدای ضبط‌شده (silencedetect)
  get-fonts.mjs   دانلود فونت
```

**موتور نسخهٔ ۲ (`reel-01.html`):** ریگ دوربین (پوش‌این/وایپ/اسنپ‌زوم)، مانیتور سه‌بعدی با چند حالت صفحه (سفید/لاگ/سایت)، کرسر با ریپل کلیک، کارت‌های علت و سوال‌ها با ورود ضربه‌ای و محو شدن، نوار مسیر (مشکل←علت←تشخیص)، فلیکر CRT، و **تایم‌لاین نسبی** (هر کی‌فریم با `b`+`o` نسبت به بیت‌ها، تا با جابه‌جایی صدا کل صحنه خودکار جابه‌جا شود).

**افکت‌های صوتی خودکار:** موتور لحظه‌های مهم را در `window.OCTO_EVENTS` اعلام می‌کند و `scripts/sfx.mjs` برای هر کدام افکت می‌سازد (همه با ffmpeg، بدون فایل صوتی): `rise` `pop` `sweep` `whoosh` `zap` `tick` `click` `ding`.

**زنجیرهٔ یک‌دستوری:** `node scripts/build.mjs` (یا دابل‌کلیک روی `build.bat`) — صدای پوشهٔ `audio/` را پیدا می‌کند، مکث‌های بلند را می‌بُرد (با محافظ که کلمات بریده نشود)، تایمینگ می‌سازد، ویدیو را با صدا و افکت رندر می‌کند → `out/reel-01.mp4`.

**حالت «خواندن روی ویدیو» (`--readalong`):** ویدیو ریتم ثابت ۴۰.۶ ثانیه‌ای دارد (`out/timeline.json`) و صدای کاربر با `scripts/fit.mjs` دقیقاً روی همان تایم‌لاین نشانده می‌شود (اگر جمله‌ای بلند باشد، حداکثر ۲۰٪ تندتر می‌شود). کاربر روی `out/reel-01-guide.mp4` ضبط می‌کند. `out/pace-guide.txt` زمان دقیق هر جمله را می‌دهد.

**نکتهٔ مهم دربارهٔ صدا:** کف نویز ضبط گوشی در این محیط حدود −۳۶dB بود؛ به همین دلیل آستانهٔ سکوت باید پایین انتخاب شود. معیار انتخاب آستانه: «آستانه‌ای که بلندترین مکث‌ها بیشترین مجموع سکوت را بدهد» (مکث بلند = مرز واقعی جمله). مرزها = بلندترین N−1 مکث.

**دو باگ مهم که در رندرهای طولانی پیدا شد (هر دو «ویدیو ناقص» می‌ساختند):**
1. `-shortest` در مرحلهٔ میکس صدا، ویدیو را روی کوتاه‌ترین جریان می‌بُرد. چون ترکیب افکت‌ها فقط تا آخرین افکت کش می‌آمد، ویدیو همیشه ۳۵.۷۵ ثانیه می‌شد. **راه‌حل:** ترکیب SFX با `apad=whole_dur` تا length ویدیو کش می‌آید.
2. گاهی یک فریم ناقص نوشته می‌شد. **راه‌حل:** چک سایز بعد از هر اسکرین‌شات (با تلاش مجدد) + بازسازی فریم‌های خراب بعد از رندر.

**انیمیشن‌های پیاده‌شده:**
بالا آمدن از اعماق با اورشوت و squash، تنفس آرام، پلک زدن، حرکت نگاه، سه حالت دهان با کراس‌فید، تکان بازوها با فاز متفاوت، ورود واژه‌به‌واژهٔ متن، هایلایت فیروزه‌ای، خط اسکن در شروع صحنه، کارت خطای شیشه‌ای، چیپ CTA.

**دموی فعلی (۳ صحنه، ۶ ثانیه):**
1. «سایتت سفید شده؟» — دهان متعجب
2. «۹۹٪ وقت‌ها پلاگینه» + کارت `Fatal error: Allowed memory size` — دهان ناراحت، نگاه به کارت
3. «بذار بررسیش کنم» + چیپ «مشاوره رایگان · octoopus.ir» — دهان خوشحال

**دستور رندر:**
```
node scripts/render.mjs --video           # → out/octo-template.mp4
node scripts/render.mjs --stills 1,3,5    # عکس تک‌فریم
```
پیش‌نیاز: Node 18+، Chrome، FFmpeg در PATH.

## ۸) اسکریپت ریلز ۱ — «صفحهٔ سفید»

قالب ثابت: ۶ بلوک × ۶–۹ ثانیه ≈ ۴۰ ثانیه. هر ۳–۴ ثانیه یک اتفاق بصری (پوش‌این، اسنپ‌زوم، گلیچ، کلیک).

| # | زمان | تصویر و حرکت | روی صفحه | دیالوگ |
|---|---|---|---|---|
| ۱ | ۰–۴ | اکتو از اعماق، پوش‌این آرام | سایتت [[سفید]] شده؟ | «سایتت سفید شده؟ قبل هر کاری این مسیر رو برو.» |
| ۲ | ۴–۹ | مانیتور سه‌بعدی می‌آد وسط، صفحهٔ سفید، فلیکر CRT | خطاش رو [[نمی‌بینی]] | «این یه صفحهٔ سفیدِ خالیه. یعنی خطا داری، ولی نمی‌بینی.» |
| ۳ | ۹–۱۸ | سه کارت پشت‌سرهم (۱، ۲، ۳) | افزونهٔ ناسازگار / خطای PHP / کمبود حافظه | «سه علت داره: افزونهٔ ناسازگار... خطای PHP... کمبود حافظه.» |
| ۴ | ۱۸–۲۷ | چک‌لیست کنار مانیتور | ۱) پنل باز می‌شه؟ ۲) آخرین تغییرت چی بود؟ | «اول: پنل باز می‌شه؟ اگه آره، مشکل از قالب یا افزونهٔ سمت سایته. اگه نه... دوم: آخرین چیزی که عوض کردی چی بود؟» |
| ۵ | ۲۷–۳۳ | کرسر می‌ره توی پنل لاگ، خط قرمز هایلایت، اسنپ‌زوم | `Allowed memory size of 134217728 bytes exhausted` | «جوابش توی لاگه. یه خط.» |
| ۶ | ۳۳–۴۰ | پول‌بک، اکتو خوشحال، چیپ CTA | بذار [[ببینم]] / تحلیل رایگان | «بذار ببینم کدومه. رایگان.» |

**کپی تأییدشدهٔ هوک (در تمپلیت اعمال شد):**
`title: "سایتت {{سفید}} شده؟"` / `sub: "قبل هر کاری این [[مسیر]] رو برو."`

**ترفند رنگ کلمهٔ «سفید»:** کلمه با `{{...}}` نوشته می‌شود و به‌جای هایلایت فیروزه‌ای، **خودش یک بلوک سفید با متن سرمه‌ای** می‌شود — یعنی همان صفحهٔ سفید، داخل خود جمله. این کار موتور اضافه دارد: `[[...]]` = هایلایت فیروزه‌ای، `{{...}}` = بلوک سفید (با فلیکر CRT).

**سه علت صفحهٔ سفید و اثر انگشتشان:**
1. **افزونهٔ ناسازگار** — پنل باز می‌شه ولی فرانت سفید؛ معمولاً بعد از آپدیت وردپرس یا نصب پلاگین
2. **خطای PHP** — `Fatal error: Uncaught Error`؛ معمولاً قالب یا کد سفارشی
3. **کمبود حافظه** — `Allowed memory size of 134217728 bytes exhausted`؛ سایت سنگین یا لوپ بی‌نهایت

نکتهٔ فنی: صفحهٔ سفید یعنی خطا هست ولی `display_errors` خاموشه → پس روایت «اول سفیدی، بعد لاگ» درست است.

**CTA:** «مشاوره رایگان · octoopus.ir» (دامنه را دستی ننویس؛ تمپلیت خودش LTR اضافه می‌کند).

**سری فرعی:** هر سه علت، یک ریلز مستقل بعدی می‌شود (قسمت ۱/۲/۳) → یک ماه محتوا از همین ریلز.

**صدا:** صدای خود کاربر، یک‌جا ضبط شود با مکث (حداقل ۰.۳۵ ثانیه) بین جمله‌ها.

**اسکریپت برچسب‌دار (فصلی sync):** هر چیزی که روی صفحه ظاهر می‌شود یک برچسب دارد
و سیستم دقیقاً می‌فهمد کدام جملهٔ ضبط‌شده مال کدام است. فایل: `template/audio/script.txt`

| برچسب | روی صفحه |
|---|---|
| `b0`…`b5` | تیتر و زیرنویس ۶ صحنه |
| `c0`…`c2` | کارت‌های سه علت |
| `q0`…`q1` | دو سوال تشخیصی |

از روی صدا تنظیم می‌شود: زمان بیت‌ها، لحظهٔ ظاهر شدن هر کارت/سوال، زوم دوربین،
لحظهٔ کلیک کرسر روی لاگ (درست قبل از آخرین کلمهٔ جمله)، و پلک زدن اکتو.

```bash
node scripts/timing.mjs --audio audio/voice.wav --lines audio/script.txt --out timing.json
node scripts/render.mjs --html reel-01.html --video --timing timing.json --audio audio/voice.wav --out reel-01.mp4
```

**وضعیت پیاده‌سازی:** سناریو بالا در `template/reel-01.html` پیاده شده و رندر گرفته شده:
`out/reel-01.mp4` — ۴۰ ثانیه، ۳۰fps، ۱۰۸۰×۱۹۲۰، ۱۱.۸MB، بی‌صدا.
(رندر کامل ۴۰ ثانیه ≈ ۶ دقیقه؛ `--fast` با فریم JPEG سریع‌تر است.)

```bash
# رندر بی‌صدا
node scripts/render.mjs --html reel-01.html --video --out reel-01.mp4

# بعد از ضبط صدا:
node scripts/timing.mjs --audio audio/voice.wav --lines audio/script.txt --out timing.json
node scripts/render.mjs --html reel-01.html --video --timing timing.json --audio audio/voice.wav --out reel-01.mp4
```
